# docs

The specification. Read these before writing code.

- `contracts.md`: the five interfaces between parts of the design. Changes go through the lead.
- `architecture.md`: every block, port, net and timing rule.
- `verification.md`: how each block is tested, bench rules, vector formats.

Owners add reports here as they produce them: `model_report.md`, `mxu_report.md`, `dma_throughput.md`.
