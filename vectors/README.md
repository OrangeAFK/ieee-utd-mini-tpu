# vectors

Test vectors generated by `python -m model.gen_vectors` from the golden model. Never edit these by hand; change the generator and regenerate.

Plain-text hex for `$readmemh`, one value per line. Formats and the list of sets: `docs/verification.md`, section 5. Benches read them with paths starting `vectors/`, since they run from the repository root.

Checked by `pytest model/gen_vectors`, which regenerates and compares.
